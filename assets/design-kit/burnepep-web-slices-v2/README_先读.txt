BURNEPEP 网页切图素材包 V2 — 先读说明
======================================
来源：本次上传图片「ChatGPT 图像 2026年9月28日 19_31_48(1).png」
实测尺寸：941 × 1672 px。

范围
- 已跳过首屏视频区域（y=51 至 423），不含该区人物、火焰或文字切片。
- 保留公共导航栏；完整覆盖 Manifesto、Token、Community、Roadmap、底部 CTA 和页脚。
- 118 个原图矩形切片，另有 58 个透明衍生版本。
- 每个版本都有 PNG 与无损 WebP：176 个 PNG + 176 个 WebP。不同格式不是不同图案。

最快使用
1. 解压整个文件夹，打开 01_asset_browser.html。按板块筛选或搜索，查看实际尺寸，复制文件路径。
2. 打开 02_layout_map.html，选择板块，在设计位置点击对应素材。
3. 打开 03_page_reference.html，检查首屏以下的完整拼接效果。
4. asset-manifest.json 包含全部路径、尺寸、原图坐标与用途；asset-list.csv 可直接查看清单。
5. site-copy.json 为从图中转录的英文正文。正文参考图片也保留在各板块内。

目录
png/              原图矩形切片，保留背景和全部可见像素。
webp/             相同切片的无损 WebP。
transparent_png/  从合成图后期抠取的透明衍生版本，不是设计原始图层。
transparent_webp/ 同一透明版本的无损 WebP。
previews/         全部切片、透明切片和分板块预览索引。

尺寸与真实性
- 本包未使用插值放大、超分辨率或 AI 重绘。裁切没有增加源图中不存在的细节。
- 请以清单中的 width / height 为准，不要把 150–200 px 的切片当作 1K 插画使用。
- 透明版的纸张/黑色背景已做后期去底，个别墨迹和做旧边缘仍会保留。
- 复杂叠压素材优先保留矩形完整版本；透明版仅作独立摆放备选。
- 海报被其他素材遮挡的部分没有补画；CTA 青蛙在原图下缘已经截断，切片仅保留可见部分。
- X 类是原图纹理采样和分隔边，不是可无限平铺的无缝纹理。
- 原图年份为 2024，文案转录保留该年份，发布前请自行核实实际内容和链接。

网页接入
- png/00_sections 为完整板块切图，可用于设计核对，但不是最终交互网页。
- 正文、导航文字、社交标签、按钮文字、路线图说明适合做成可编辑 HTML。
- 卡片插画与艺术字可引用相应单独图片，避免将整张长截图拉伸铺满桌面。
- PNG 和 WebP 二选一即可；透明素材有独立目录，不能把矩形版当作透明版。
- 在高像素密度屏幕上展示前，应结合实际显示尺寸检查清晰度。

关于上一轮独立大图
上一轮生成的 10 张独立大图另放在单独的备选包中，未混入本包的原图切片。
这些备选图属于 AI 重绘，不是同一设计的精确放大版，局部构图/文字比例可能不同。
